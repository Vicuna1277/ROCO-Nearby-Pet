# ROCO附近精灵

洛克王国手游查看附近精灵信息与地图探索辅助工具，支持奇遇战斗信息查看(S5)、世界存档，以及与 Clicker 联动执行自定义流程。


本仓库用于软件介绍，目前不托管完整工程源码、精灵数据表或地图资源。

PC端以后更新的时候会另起一个仓库存放。

## 主要功能

### 附近精灵信息

采集游戏通信中已下发的精灵信息，展示名称、声音、身高、体重、距离及八方向方位。身高、体重有对应数据表时按百分比显示，缺少换算数据时保留实际数值。

支持名称与稀有特征筛选：

| 筛选项 | 条件 |
| --- | --- |
| 满声 | 声音为100或-100 |
| 婉转声 | 声音96～100 |
| 粗嗓门 | 声音-100～-96 |
| 大块头 | 身高100% |
| 小不点 | 身高0% |

声音选项之间取并集，体型选项之间取并集，两组条件与名称取交集。可自定义显示半径，也可关闭野生精灵显示，只查看战斗信息。全部不勾选时可预览普通精灵。

目标精灵可保留历史记录；为减少刷新负担，仅维护最近20条目标的动态距离，其余历史记录静态显示。普通精灵不作为稀有历史长期保存。

### 独立悬浮窗

精灵列表、地图和脚本开关分别独立显示，方便边玩边查看：

- 列表和地图可收起、拖动及调整尺寸。
- 精灵条目按声音、满声和极端身高着色。
- 精灵列表采用紧凑布局，按内容调整高度。
- 符合当前筛选的新目标可触发列表按钮闪色提醒。
- 提示使用系统默认文本Toast，内容统一为“ROCO：文本”。

### 战斗信息

进入战斗后，精灵悬浮列表自动切换到敌方信息；收起状态下会弹出紧凑信息，战斗结束后恢复野生列表或收回战斗提示。

可查看已解析的声音、身高、体重、污染/奇异/异色标签及性格；奇遇外壳被打破后，收到真身消息会更新目标信息。支持展示已解析的多个敌方目标。

目前屏蔽已确认的PvP、花种和Boss战斗类型。**性格相关信息仅按S5已验证数据解析，其他赛季需要重新验证。**

### 地图与探索涂色

地图跟随玩家位置，以可自定义半径标记走过的区域，便于查看未探索位置。

- 支持地图拖动、双指中心缩放和悬浮地图尺寸调整。
- 收起后重新展开回到玩家位置，保留缩放比例。
- 可打开大地图查看完整涂色分布。
- 涂色持续保存，并可手动清除。

### 按世界保存

不同世界分别保存精灵记录和探索涂色，支持自定义名称、切换世界、导入和导出世界存档。可单独删除精灵记录或涂色。

更新版本前建议导出存档；安装包签名或应用包名发生变化时，不保证原数据能直接继承。

### 自定义流程脚本

通过简单代码描述奇遇处理条件，ROCO读取信息并决定执行哪个Clicker脚本。

- 脚本列表支持新建、编辑和删除。
- 独立编辑页支持行号、自动缩进、格式化与保存前语法检查。
- 支持名称数组、条件判断、等待、提示和按名称执行Clicker脚本。
- 独立脚本悬浮开关控制自动运行，默认关闭。
- 每场确认奇遇从头执行一次，`stop()`只停止本场，下一场仍可运行。
- 内置字段说明书、**S5示例**与不执行点击的信息示例。

可用字段包括精灵名称、声音、体型百分比与实际数值、血脉、异色，以及S5性格`nature`和正向属性`nature_plus`。未知信息返回null，性格缺失不影响基础信息就绪判断。

S5示例可自行维护高价值与S5精灵名单。异色优先停止、奇异优先捕捉；S5双牌优先停止，其后高价值普通/混血目标使用骰子，其余满声捕捉、其他目标击败。污染有独立处理分支。具体以编辑器中可查看、修改的模板代码为准，±94是模板条件，不改变附近筛选的±96阈值。

## 运行要求

- Android **12及以上**。
- 当前安装包面向 **arm64-v8a** 设备。
- ROCO通过本地VPN采集，不需要ROOT，也不需要另行安装PCAPdroid或Python。
- 悬浮功能需要“显示在其他应用上层”权限；按系统要求允许通知。
- VPN切换可能使游戏短暂断线，需要回到游戏等待重连。
- 使用Clicker联动时，Clicker需单独完成ROOT或Shizuku授权。

## 开始使用

1. 打开ROCO，在主页点击“开启采集”，允许系统VPN请求。
2. 返回游戏等待重连与数据下发，确认精灵或战斗信息出现。
3. 按需开启精灵和地图悬浮窗。
4. 在精灵页设置筛选与显示半径，在主页设置涂色半径并选对世界存档。
5. 如需自动流程，再配置Clicker与ROCO脚本，并手动打开脚本执行开关。

底部三页为“主页 / 精灵 / 脚本”，支持左右滑动。主页右上角信息图标可查看软件介绍和项目主页。

## Clicker联动

[Clicker项目主页](https://github.com/Vicuna1277/Clicker)

ROCO负责条件判断和流程控制，Clicker负责执行点击动作。请先在Clicker授权页添加当前ROCO的实际包名：

- 正式版：`ink.roco.nearby`
- 调试版：`ink.roco.nearby.debug`

在Clicker中建立与流程代码完全同名的脚本。内置S5示例使用“捕捉”“击败”“奇异骰子”。“奇异骰子”之后是否继续捕捉，取决于该Clicker脚本自身内容，ROCO不会额外补充点击。

ROCO会等待当前Clicker脚本完成再进入后续语句；战斗确认结束或手动停止时，会要求停止当前调用。完成回报仅表示点击流程返回，不代表游戏捕捉成功。

## 使用限制

- 只显示已收到并能解析的数据，不保证随时开始采集都立即获得完整信息。
- 不提供战斗外预测奇遇真身的功能。
- 精灵位置取最近解析到的坐标，不保证跟随精灵的实时行为移动。
- 缺少体型换算表时不生成假百分比；游戏更新可能影响解析与数据对应。
- 自动奇遇流程需要先确认龙棋士外壳。缺少外壳阶段，或存在多个敌方而无法唯一确定目标时，不会猜测自动操作对象。
- 厂商后台限制可能中断采集或Clicker执行，必要时允许两款应用后台运行。
- 模板会实际操作当前游戏画面，使用前应检查名单、分支、脚本名称与点击内容。
